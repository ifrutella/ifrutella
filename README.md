# Ivan

Web developer in Oslo. I build fast, plain websites and small Python tools
that save people time.

I run [Caissa Codex](https://chesscodex.org), a free reference of 3,690 named
chess openings: the moves on a board, Lichess statistics by rating, master games
and Stockfish evaluations. It is PHP and SQLite with no framework, on a server I
look after myself. The code is open: [ifrutella/chesscodex](https://github.com/ifrutella/chesscodex).

Some smaller work, with live demos on [my portfolio](https://ifrutella.github.io/):

- [page-speed-demo](https://github.com/ifrutella/page-speed-demo): one landing page before and after speed work, with the measurements
- [oslo-bike-shop-demo](https://github.com/ifrutella/oslo-bike-shop-demo): a Norwegian and English site for a made-up bike workshop
- [excel-report-automation](https://github.com/ifrutella/excel-report-automation): turns messy CSV and Excel exports into one clean report

I work with PHP, SQLite, JavaScript, HTML and CSS; Python with pandas and
openpyxl; Linux, nginx and Cloudflare; and Search Console for SEO.

Away from the keyboard: chess and Counter-Strike 2.
